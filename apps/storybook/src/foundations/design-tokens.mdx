# Design tokens

Tokens are defined once, in TypeScript, in `@virgulimaginaria/design-tokens` and published three ways:

| Import                                       | Use it for                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------- |
| `@virgulimaginaria/design-tokens`            | Typed values and `cssVar("--color-primary")` in TypeScript.                     |
| `@virgulimaginaria/design-tokens/tokens.css` | Plain CSS custom properties, without Tailwind.                                  |
| `@virgulimaginaria/design-tokens/theme.css`  | A Tailwind CSS v4 theme. Already included by `@virgulimaginaria/ui/styles.css`. |

Names are **semantic** (`--color-danger`, not `--color-red-600`) and never refer to a product, screen or business concept. The values are neutral placeholders: applications apply their brand by overriding the variables.

The dark scheme applies inside `.dark` or `[data-theme="dark"]`; use the toolbar to switch it.

## Colour

Each `*-foreground` colour is meant to be placed on its base colour and keeps a WCAG AA contrast ratio against it.
